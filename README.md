## about

I build backend systems that stay up when things get messy. Most of my time goes into APIs, databases, and the Linux boxes that run them, along with the firewall rules that keep the bad traffic out before it ever reaches the application. I'd rather ship something dependable than something trendy.

Outside of shipping, I spend time hardening the servers I run and slowly working through reverse engineering fundamentals, because understanding how something breaks is the fastest way to learn how to build it properly.

## security.conf

Hardening isn't a separate task from development, it's part of shipping.

| rule | description |
|---|---|
| `netfilter` | iptables / nftables rules written and maintained by hand, not left on distro defaults |
| `rate-limit` | abuse and floods stopped before they reach the application layer |
| `port-hardening` | exposed ports minimized, services isolated from each other |
| `sandbox-first` | every rule tested in an isolated environment before it touches production |
